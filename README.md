# DinoRush - Epic Dinosaur Adventure

A fun HTML5 dinosaur runner game where you control a dinosaur and avoid obstacles for as long as possible!

## How to Play

1. Open `index.html` in any modern web browser
2. Press Space, Up Arrow, or tap the Jump button to start the game
3. Press Space/Up Arrow or tap the top half of the screen to jump over obstacles
4. Press Down Arrow or tap the Duck button to duck under flying obstacles
5. Try to get the highest score possible!

## Controls

- **Keyboard:**
  - Space / Up Arrow: Jump
  - Down Arrow: Duck
  
- **Mobile/Touch:**
  - Tap top half of screen: Jump
  - Tap bottom half of screen: Duck
  - Use on-screen buttons

## Features

- Responsive design works on desktop and mobile
- Increasing difficulty as your score goes up
- High score tracking
- Dynamic obstacle spawning
- Beautiful visual effects
